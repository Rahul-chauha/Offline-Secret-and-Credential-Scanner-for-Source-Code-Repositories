Core Detection Pipeline

01. SAFE HANDLING

Input Ingestion

Protects against Zip-Slip traversal and Zip-Bomb attacks. Skips binary files and dependency folders.

02. PATTERNS

Pattern Matching

Matches known signatures: AWS, GitHub tokens, private keys, database URIs, Slack, OpenAI, Stripe, etc.

03. ENTROPY

Shannon Entropy

Calculates information randomness to catch high-entropy credentials that evade regular patterns.

04. FILTERING

False-Positive Filter

Suppresses dummy placeholders, template configs (.env.example), and test suite mock credentials.
